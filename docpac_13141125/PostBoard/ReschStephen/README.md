This program acts as a posting board for job listings. Users can create their own posts with a title and description. Everyone can view the info, along with who made the post and when it was created. Posters can edit and delete their own posts. People can leave comments under posts, and only the post author can delete them. When a post is completed, any comments attached will also be deleted. To see updates from other users on the viewpage for listings, users must refresh the page. In the future, I could add the ability for the page to be updated for everyone in real time, but this still works fine.
