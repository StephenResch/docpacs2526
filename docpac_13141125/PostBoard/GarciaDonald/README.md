# POST BOARD
For this week, my project is a post board. The goal of this is to have job listings for those who need help with something.

## HOW DO I SET THIS UP?
You will need to install the following:
- Node.js
- Express.js
- EJS
- SQLite3
You are also going to need a formbar account for this project to work the way it is intended to.

## How does this project work?
Once you make a formbar account and login, you are taken to the index page where you have three options: Check the post board, post a job listing, or log out.

### The Post Board

This is the place where you can find job listings. For example, let's say I need some quick cash to pay for a small fee that is due soon. I find a job listing that says to be a nightguard for a local restaurant. If i make it through one night, the pay is $25, which is more than enough for my fee.
### Post A Job
Need help for something? This is your place to go. Lost your earbud? Make a job listing to get someone to help you find it. Need someone to watch your dog? Make a job listing to find someone in the area. You name it, post the listing!

## The Best Part?
If you found someone for the job, you can just delete it or edit the post saying you found someone! Really, it's that simple. Just go the buttons below the posts or comment (depending on your situation), and you'll be taken to a confirmation page. You know what to do from there!
