To use this is pretty simple. You will access the post board by pressing the first button, which will show any and all post you have. You can create a post with the button at the bottom. To view a profile just click on the users name in the post on the postboard. To view the post and all the comments on it you have to click on the title of the post. Once viewing a post you can edit or delete the post and delete comments, which only show to the owner.
