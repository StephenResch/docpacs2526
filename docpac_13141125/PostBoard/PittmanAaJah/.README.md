Description
Post Board Assignment

This project uses Node.js and Express and connects to an OAuth server for authentication. It uses SQLite to store users, posts, and comments.

When a user logs in they are saved to the local db if they arent already there. 

Users can create posts with: 
Title
Description
Creator name
Timestamp
Users can edit or delete only their own posts.

All users can comment on any post and ther user who made the post can delete comments.

How to Use

install with:

npm install

.env file including:

SESSION_SECRET=yourSecret
AUTH_URL=http://yourAuthServer
THIS_URL=http://localhost:3000
API_KEY=yourApiKey
PORT=3000

start the server:
node app

visit 
http://localhost:3000
